# MAROO — فحص محلي أولي (PoC)

هذه صفحة اختبار منفصلة لمعاينة ملف GLB وكاميرا فيديو على الجهاز نفسه. **ليست نموذج MAROO مكتملًا، ولا تتعقب الوجه أو الجسم أو اليدين، ولا تحرك الشخصية أو تزامن الشفاه، ولا تتصل بـTikTok LIVE Studio أو OBS.** لا تغيّر مسارات البرنامج أو إعدادات البث.

## المتطلبات

- Node.js 18 أو أحدث لتشغيل الخادم.
- متصفح حديث يدعم WebGL و`getUserMedia`، مثل Chrome أو Edge.
- للسماح بالكاميرا، افتح الصفحة على الجهاز الذي يشغّل الخادم باستخدام `localhost` أو `127.0.0.1`، وامنح إذن الكاميرا من المتصفح عند الطلب.

## التشغيل من جذر المستودع

```bash
node scripts/maroo-poc-server.mjs
```

ثم افتح على **الجهاز نفسه**: <http://127.0.0.1:4179/>

لإيقاف الخادم اضغط `Ctrl+C`. يمكن اختيار منفذ محلي آخر عند الحاجة. في Windows PowerShell:

```bash
$env:MAROO_POC_PORT = "4180"
node scripts/maroo-poc-server.mjs
```

الخادم مربوط حصريًا بـ`127.0.0.1` ويقدم أربعة مسارات محددة فقط؛ لا تفتحه على الشبكة المحلية أو الإنترنت، ولا تستخدم نفقًا عامًا. إذا شُغّل على اللابتوب فلن تصبح كاميرا الهاتف مرئية تلقائيًا للابتوب؛ ستظهر فقط كاميرا يراها نظام التشغيل كجهاز فيديو، أو شغّل الصفحة على الجهاز الذي تريد فحص كاميرته.

## الاستخدام

- اختر ملف `.glb` من الجهاز. يُقرأ محليًا في المتصفح عبر رابط مؤقت، ويُلغى الرابط عند استبدال الملف أو إغلاق الصفحة. لا يتضمن هذا التوزيع ملف النموذج نفسه.
- اضغط «تشغيل الكاميرا» لاختبار فيديو مباشر. لا يطلب التطبيق الميكروفون، ويستخدم قيودًا مثالية قدرها 640×360 و15 إطارًا/ثانية، بحد أعلى 24 إطارًا/ثانية. أوقف الكاميرا بالزر؛ كما تتوقف مساراتها عند إخفاء الصفحة أو مغادرتها. تغيير اختيار الجهاز أثناء انتظار الإذن يلغي الطلب المنطقي، لكن متصفح النظام قد يبقي نافذة الإذن حتى يرد المستخدم؛ أي تدفق يصل بعد الإلغاء يُوقف فورًا.
- تعطل WebGL يمنع عرض GLB لكنه لا يعني فشل الكاميرا. نجاح عرض الملف أو الفيديو لا يثبت صلاحية الـrig أو أداء الجهاز أو الجاهزية للبث.

## إعادة البناء والاختبارات

الملف `app.bundle.js` مضمّن، لذا لا يلزم تثبيت مكتبات لبدء الخادم. إذا عُدّل `app.js` وأردت إعادة البناء، يتطلب السكربت `esbuild` و`three` المعرّفين في `world-challenges-live/package.json` والمثبتين ضمن `world-challenges-live/node_modules`:

```bash
npm --prefix world-challenges-live install --include=dev
node scripts/build-maroo-poc.mjs
```

ثم شغّل:

```bash
node scripts/test-maroo-poc.mjs
npm --prefix world-challenges-live run test:quality
```

تُبنى المكتبات محليًا من حزم مفتوحة المصدر مع الاحتفاظ بإشعار ترخيص Three.js في `THIRD-PARTY-NOTICES.md` والحزمة. لا يستدعي البناء خدمة مدفوعة.

## حدود الخصوصية والجاهزية

الفيديو لا يُسجل أو يُخزن أو يُرفع بواسطة هذه الصفحة؛ الخادم لا يستقبل ملفات أو إطارات أو صوتًا. لا تستخدم PoC أثناء بث حي أو كبث متصفح للمشاهدين. فحوص البيئة الحالية لم تثبت دعم WebGL أو تشغيل الكاميرا على جهاز Dell الفعلي، ولم تختبر TikTok LIVE Studio أو OBS. يلزم اختبار محلي على جهاز الإنتاج قبل اتخاذ أي قرار لاحق، وتبقى معالجة الحركة والوجه واليدين والصوت والربط والاستقرار وبروفة الرجوع بنودًا مفتوحة.
