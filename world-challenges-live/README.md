# 🌎 عالم التحديات — LIVE GAME SHOW

لعبة مسابقات تفاعلية مباشرة مع AI للبث المباشر على TikTok ومنصات التواصل الاجتماعي.

## ✨ المميزات

- 🤖 **مولد أسئلة بالـ AI** — يدعم Gemini (مجاني) و OpenRouter
- 🎬 **لايف كامل** — تجهيز جولات متعددة دفعة واحدة لمدة 1-3 ساعات
- ⏱️ **مؤقت تفاعلي** — مع عد تنازلي بصري وصوتي
- 🏆 **نظام نقاط متعدد الفرق** — يدعم 2-6 فرق
- 🎉 **تأثيرات بصرية** — confetti، أنيميشن، أصوات
- 📱 **PWA** — يعمل offline ويمكن تثبيته على الموبايل
- 🔒 **مفتاح API محمي** — في الخادم وليس في المتصفح

## 🚀 التشغيل السريع

### 1. تثبيت المتطلبات

```bash
npm install
```

### 2. إعداد مفتاح API

```bash
cp .env.example .env
# عدّل ملف .env وأضف مفتاح Gemini API المجاني
```

احصل على مفتاح مجاني من: [Google AI Studio](https://aistudio.google.com/app/apikey)

### 3. التشغيل

```bash
npm start
```

افتح المتصفح على: `http://localhost:3000`

## 🎮 طريقة الاستخدام

1. **اختر طريقة التشغيل**: جولة واحدة / لايف كامل / بنك أسئلة
2. **حدد الفئة**: معلومات عامة، جغرافيا، علوم، تاريخ، دين، ألغاز، وغيرها
3. **حدد الصعوبة**: سهل / متوسط / صعب / متنوع
4. **حدد عدد الأسئلة**: من 1 إلى 50
5. **أضف الفرق**: الشباب ضد البنات (أو فرق مخصصة)
6. **اضغط "جهّز الجولة بالـ AI"**
7. **ابدأ اللايف!** 🎉
