# تشغيل محطة الفضاء والبث التجريبي

## تشغيل المشهد

من جذر المشروع شغّل:

```bash
pnpm install
pnpm build
PORT=3000 pnpm start
```

افتح `/space-station/`. المسار مستقل عن عالم التحديات، ولا يحتاج إلى تعديل ملفات اللعبة الأساسية.

## تفعيل TikTok LIVE

من لوحة المضيف أدخل `@username` الخاص بالبث، أو أدخل `Room ID` إذا كان حل الاسم غير متاح، ثم اضغط **اتصال مباشر**. الواجهة تتصل بخادم التطبيق عبر:

- `GET /live/status` لقراءة الحالة.
- `GET /live/events` لاتصال SSE بالأحداث.
- `POST /live/connect` لبدء الاتصال باسم المستخدم من لوحة المضيف.
- زر الفصل يوقف اتصال المتصفح؛ إعادة الاتصال الخادمي تتم وفق سياسة الموصل وإعادة المحاولة.
- `GET /health` لفحص جاهزية الخادم.

لا تضع أي مفتاح أو Cookie داخل JavaScript المتصفح. إن احتاج مزود التوقيع إلى مفتاح خادمي، مرّره كمتغير بيئة في الخادم فقط، مثل `TIKTOK_LIVE_SIGN_API_KEY`.

## الأحداث المستخدمة داخل المشهد

التعليقات تنشئ مشاركًا وتفعّل الرقص عند كلمات التحكم المحددة. الهدايا تنشئ مشاركًا لمرسلها وتربط قيمة Diamonds بحركة مختلفة: رقص، شقلبة، انعدام جاذبية جماعي، أو حفلة جماعية. الإعجابات تحدّث العداد، بينما المتابعات والمشاركات والانضمام تنشئ حضورًا بصريًا للمشاهد.

## القيود التي يجب اعتمادها قبل النشر

الموصل الحالي `tiktok-live-connector` غير رسمي ويقرأ Webcast الداخلي، وقد يتغير دون إشعار أو ضمان uptime. كما أنه مرخّص AGPL-3.0-only. قبل استخدامه في منتج تجاري يجب مراجعة الالتزامات القانونية واختيار أحد المسارين: تشغيله مع قبول شروط الترخيص، أو استبداله بموصل MIT/خدمة مُدارة بعد التحقق من السعر وشروط الاستخدام.

بيانات البث الحقيقية لم تُختبر إلا بعد توفير بث يملكه المستخدم وحساب صالح وبيئة Server متاحة. أحداث Demo للاختبار المحلي لا تمثل ضمانًا بأن TikTok سيقبل الاتصال أو أن كل أنواع الهدايا ستصل بنفس الشكل.

## التحقق قبل البث التجريبي

نفّذ `pnpm typecheck` و`pnpm test` و`pnpm build`، ثم افحص `/health`. اختبر أولًا بعدد 10 مشاركين، ثم 25، ثم 40، وسجّل FPS وذاكرة المتصفح على جهاز GPU حقيقي متوسط. لا تعتمد على SwiftShader وحده للحكم على أداء البث.
